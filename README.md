# 可复用项目协作流程模板

这是一套**交给Codex或其他智能体阅读的初始化资料**。智能体先了解当前项目，再询问你缺少的关键信息；你回答后，它在当前项目目录内建立项目思路、节点计划和Git协作约定。初始化完成并验证资料独立可用后，你可以自行删除这个模板文件夹。

智能体首先阅读本目录的 [AGENTS.md](AGENTS.md)，并按照其中步骤在目标项目建立工作模式。

## 目录

```text
项目协作流程模板/
├── README.md                              本说明
├── AGENTS.md                              给智能体的初始化操作说明
└── 项目文件/                              可复制到目标项目
    ├── AGENTS.md                          通用协作约定
    ├── docs/
    │   ├── 项目思路与技术方案.md            目标、思路、架构、技术选择和验证
    │   ├── 项目节点实施与验收计划.md       节点计划和结果台账
    │   └── 开发与Git协作规范.md            工作方式和提交格式
    └── 提示词/
        ├── 01_项目初始化与规划.md          建立计划，不自动开始编码
        ├── 02_执行指定节点.md              授权一个节点
        └── 03_记录验收与修复.md            记录验收或要求修复
```

## 告诉智能体这样做

在Codex或能访问文件的智能体中打开**目标项目**，然后发送：

```text
请读取桌面的「项目协作流程模板」文件夹，参照其中AGENTS.md，
先了解当前项目，再向我询问建立项目思路、节点规划和Git管理所需的信息。
等我回答后，在当前项目目录内初始化工作模式，把思路和计划落实到文件供我审核。
初始化完成后我会删除这个模板文件夹，请确保项目资料不依赖它；先不要开始功能编码。
```

如果智能体无法识别“桌面”位置，可给出本机实际路径；当前电脑为 `/Users/binfinity/Desktop/项目协作流程模板`。换电脑或系统后，使用该电脑上的模板路径。若目标项目不是当前打开的目录，也应在消息中写明目标路径。

智能体会先询问项目目标、交付、约束和必要的Git偏好，避免重复问已有明确答案。收到你的答复后，它负责在现有项目目录创建或合并文件，说明目标、整体思路、技术选择、文件结构、数据来源和验证方式，再整理符合项目实际的节点，并按授权处理Git。若已有项目资料或同名文件，应先读取并保留，不得覆盖未提交改动或重置进度。

项目内的协作规则、思路、节点计划、Git规范及后续提示词应是项目内的真实文件，链接使用项目内相对路径。等智能体报告初始化及独立性检查完成后，你可以删除本模板目录；智能体不应擅自替你删除。

也可以使用更详细的 [项目初始化与规划提示词](项目文件/提示词/01_项目初始化与规划.md)。审核计划后，使用 [执行指定节点提示词](项目文件/提示词/02_执行指定节点.md) 单独授权一个节点；需要记录通过或要求修复时，使用 [验收与修复提示词](项目文件/提示词/03_记录验收与修复.md)。

## 日常执行顺序

```text
只读了解现有项目 → 询问必要信息 → 用户回答
    ↓
在当前目录建立独立可用的项目思路与技术方案 → 规划节点 → 用户审核
    ↓
明确授权一个节点 → 实现 → 测试 → 回填结果 → 小步提交
    ↓
等待用户验收 → 用户明确授权下一节点
```

AI每次都应读取目标项目中的节点计划和前置结果。必需测试未运行、跳过或失败时不能填“通过”；真实结果、失败原因与证据路径记在同一计划文件中。项目版本通过Git管理，不需要每次另建备份或历史记录文件。

## Git提交示例

```text
feat(登录): 添加用户登录功能
fix(数据): 修正缺失值处理
docs(节点计划): 补充数据处理验收标准
test(接口): 验证无效输入的返回结果
```

`type`使用小写英文，作用域、描述、正文和页脚以中文为主；专有名词和必要的标准标识保留原文。详细规则在 [开发与Git协作规范](项目文件/docs/开发与Git协作规范.md)。

## 适用边界

- 模板适用于已有项目或新项目；不预设编程语言、框架、数据源、操作系统或具体业务。
- AI需要能够访问目标仓库和运行环境才可真实修改、测试和提交；纯聊天平台只能给出可应用的内容或步骤，不能声称实际执行成功。
- 推送权限按目标项目和本次任务填写；远程仓库、分支和历史改写不会因为复制模板而自动授权。
- 提示词文件是模板，复制进项目或阅读文件本身不等于已经授权编码。只有用户实际指定节点和任务时，才构成该次授权。
- 各项目可能已有自己的约定、交付格式或必须保留的文件，初始化时应先核对并合并；明确的用户要求优先。
